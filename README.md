# Flashcard Study App

A simple command-line flashcard application with spaced repetition for effective studying. This will be re-made in Flask to work with the web.

## Status and Information 
🚧 Work in progress - currently starting core features. Update 1> 2/15/2026 > I added in the classes of card and deck where in Card class we define what a card is and all the properties of a card and the changes of intervals of cards according to the users idea of easy,medium and hard questions. In the deck class we create the "deck" in the form of a list and store it having 2 decks with one being the active queue and one being the due queue.

## Planned Features
- Create custom flashcard decks
- Spaced repetition algorithm for optimal review timing
- Save/load decks to JSON
- Track progress on each card
- Crazy help on study crams before exams
